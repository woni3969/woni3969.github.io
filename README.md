# 광동고등학교 과학 수업 자료실

2022 개정교육과정 기반 중·고등학교 과학 교과 수업 자료
개념 설명 + 인터랙티브 시뮬레이션 + 형성평가

## 폴더 구조

```
/
├── index.html              ← 과목 목록 (첫 페이지)
└── mechanics-energy/       ← 역학과 에너지 (고등학교 진로선택)
    ├── index.html          ← 단원 목록
    ├── 1~9차시 수업 자료(.html)
    └── 형성평가(6~9차시 .html / 1~5차시 노션 .md)
```

## 과목 현황
- **고등학교**: 물리학(준비 중) · **역학과 에너지(공개 · 9차시)** · 전자기학과 양자(준비 중)
- **중학교**: 과학 1 · 과학 2 · 과학 3 (준비 중)

## 새 과목 추가 방법
1. 과목 폴더 생성 (예: `em-quantum/`, `science1/`)
2. 폴더 안에 `index.html`(단원 목록)과 차시 파일 배치
3. 루트 `index.html`의 해당 과목 카드를 `<a class="subject" href="폴더명/index.html">`로 연결

## GitHub Pages 배포
저장소 Settings → Pages → Branch(main)/root 지정 후,
`https://<사용자>.github.io/<저장소>/` 로 접속하면 첫 페이지(index.html)가 열립니다.
